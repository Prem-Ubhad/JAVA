# Student Management System (Core Java)

## Description
This is a console-based Java application developed using Core Java.
It allows users to manage student records using CRUD operations.

## Features
- Add Student
- View All Students
- Search Student by ID
- Delete Student

## Technologies Used
- Java
- OOP Concepts
- Collections (ArrayList)

## Project Structure
- Student.java
- StudentService.java
- MainApp.java

## How to Run
1. Open the project in any Java IDE
2. Compile and run MainApp.java
3. Follow the menu options on console
